#  Sabores Reservas — Sistema de Gestão e Agendamento de Restaurantes

O **Sabores Reservas** é uma aplicação robusta desenvolvida para o gerenciamento de reservas, controle de mesas e otimização do atendimento em restaurantes. Por se tratar de um sistema que lida com dados críticos de agendamento em tempo real e regras complexas de negócio, o projeto exigiu uma arquitetura sólida no back-end e segurança rigorosa nos acessos.

##  Minha Contribuição Técnica no Projeto
No desenvolvimento desta aplicação, atuei diretamente em duas frentes de grande impacto na usabilidade e na confiabilidade do produto:

* **Desenvolvimento de Front-end:** Construção de componentes de interface responsivos, focando na experiência do cliente ao selecionar reservas disponíveis na agenda do restaurante.
* **Módulo de Segurança (Recuperação de Senhas):** Fui o responsável por projetar a lógica de recuperação de acessos do sistema. Desenvolvi o fluxo seguro no back-end que engloba a geração de tokens temporários de redefinição com tempo de expiração e a integração do serviço de envio para os usuários.

##  Desafios de Engenharia Superados
* **Prevenção de Overbooking:** Apoio na lógica de negócios para impedir reservas duplicadas (conflito de horários para a mesma mesa).
* **Segurança e Criptografia:** Aplicação de boas práticas de segurança no tratamento de credenciais e fluxos de autenticação sensíveis.

##  Stack Tecnológica
* **Back-end:** PHP / Laravel Framework (Roteamento, ORM Eloquent e Controle de Sessões).
* **Front-end:** Interfaces responsivas para controle de agendamento do usuário.
* **Banco de Dados:** Estrutura relacional para consistência e integridade das tabelas de reservas e usuários.
